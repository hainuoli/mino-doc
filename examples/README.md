# Examples

Keep `mino` and `mino-doc` as sibling checkouts. Run commands from this directory.

| Example | Command |
| --- | --- |
| Hello World | `go run ./hello` |
| Progressive adoption | `go run ./progressive` |
| ServeMux migration | `go run ./migrate` |
| JSON | `go run ./packages/jsonx` |
| Errors | `go run ./packages/errorx` |
| Field mapping | `go run ./packages/mapping` |
| Middleware | `go run ./packages/chain` |
| Request binding and responses | `go run ./packages/httpx` |
| Routing | `go run ./packages/rest` |

Run one HTTP example at a time; each listens on `:8080`.
