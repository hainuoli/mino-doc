## Defaults

| Setting | Default | Configuration |
| --- | --- | --- |
| JSON codec | `encoding/json` | `jsonx.SetCodec`, process-wide |
| JSON body limit | 8 MiB | `httpx.WithMaxJSONBody`, per call |
| Binding order | JSON → form → query → header → path | Present values from later sources override earlier ones |
| Validation | Call the target’s `Validate() error` | Automatic only in `httpx.Parse` |
| Path cleaning, escaped matching, slash redirects | Off | Enable with mux options |
| Automatic redirect status | 307 | `rest.WithRedirectStatus` |
| Error responses | `DefaultErrorHandler` | Server-error details are hidden by default |

Configure the global codec and error mapper at startup. Finish route registration before serving. See [ServeMux migration](./migration.mdx) for path policies.

## Package relationships

All six production packages depend only on Mino and the Go standard library:

```text
rest         → rest/chain
rest/httpx   → core/jsonx, core/mapping, core/errorx
core/mapping → core/errorx
```
