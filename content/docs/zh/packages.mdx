## 选择包

| 使用指南 | 职责 | API |
| --- | --- | --- |
| [`core/jsonx`](./jsonx.mdx) | JSON 编解码与 codec 配置 | [API](https://pkg.go.dev/github.com/hainuoli/mino/core/jsonx) |
| [`core/errorx`](./errorx.mdx) | 错误包装、顺序执行与并发聚合 | [API](https://pkg.go.dev/github.com/hainuoli/mino/core/errorx) |
| [`core/mapping`](./mapping.mdx) | tag 字段绑定与类型转换 | [API](https://pkg.go.dev/github.com/hainuoli/mino/core/mapping) |
| [`rest/chain`](./chain.mdx) | 标准 HTTP 中间件组合 | [API](https://pkg.go.dev/github.com/hainuoli/mino/rest/chain) |
| [`rest/httpx`](./httpx.mdx) | 请求绑定、验证、错误与 JSON 响应 | [API](https://pkg.go.dev/github.com/hainuoli/mino/rest/httpx) |
| [`rest`](./rest.mdx) | 路由、分组、挂载与路径策略 | [API](https://pkg.go.dev/github.com/hainuoli/mino/rest) |

## 默认配置

| 项目 | 默认值 | 说明 |
| --- | --- | --- |
| JSON codec | `encoding/json` | `jsonx.SetCodec` 按进程配置 |
| JSON body 上限 | 8 MiB | `httpx.WithMaxJSONBody` 按次调整 |
| 请求绑定顺序 | JSON → form → query → header → path | 后续存在的输入覆盖之前的值 |
| 验证 | 调用目标的 `Validate() error` | 仅 `httpx.Parse` 自动执行 |
| 路径清理、转义匹配、尾斜杠重定向 | 关闭 | 通过 mux 选项启用 |
| 自动重定向状态码 | 307 | `rest.WithRedirectStatus` 设置 |
| 错误响应 | `DefaultErrorHandler` | 服务端内部细节默认隐藏 |

全局 codec 和错误映射器在启动阶段配置；路由在开始服务前完成注册。路径策略见 [ServeMux 迁移](./migration.mdx)。

## 包之间的关系

六个生产包只依赖 Mino 自身与 Go 标准库：

```text
rest         → rest/chain
rest/httpx   → core/jsonx, core/mapping, core/errorx
core/mapping → core/errorx
```
